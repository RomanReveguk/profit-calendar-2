# Profit Calendar 2.0

**🔗 Відкрити застосунок: https://romanreveguk.github.io/profit-calendar-2/**

Сучасний робочий календар із розрахунком робочих годин на місяць. Показує норму годин, скільки вже відпрацьовано, враховує святкові дні України та дозволяє гнучко налаштовувати години.

> Переосмислена версія [profit-calendar](https://igorsegodin.github.io/profit-calendar/) — сучасний вигляд, теми, налаштування годин та автоматичні свята.

## Можливості

- 📅 **Перегляд місяця або всього року** одним кліком.
- ⏱️ **Розрахунок робочих годин**: норма місяця + скільки відпрацьовано на сьогодні (з прогрес-смужкою).
- 🇺🇦 **Свята України автоматично** — тягнуться з публічного API [Nager.Date](https://date.nager.at) для будь-якого року, з кешем і офлайн-fallback (рухомі Пасха/Трійця рахуються вбудованим алгоритмом).
- ⚙️ **Меню налаштувань**:
  - годин на день (стандарт) + швидкі пресети 8 / 6 / 4;
  - робоча субота;
  - початок тижня (Пн/Нд);
  - тема (світла / темна / системна);
  - мова (українська / English);
  - оновлення свят, скидання перевизначень, **експорт/імпорт JSON** (перенести налаштування між ПК).
- 🖱️ **Клік по дню** — задати години саме для цього дня (напр. пів дня = 4), позначити відсутність / свято / робочий, скинути до стандарту.
- 🌗 Світла й темна теми, адаптив під мобільні.
- 💾 Усе зберігається локально (`localStorage`) — працює офлайн після першого відкриття.

## Запуск локально

Просто відкрий `index.html` у браузері. Жодної збірки чи залежностей — це один HTML-файл на vanilla JS.

## Технології

Vanilla JavaScript, сучасний CSS (CSS-змінні, теми), нативні `Date`/`Intl` — без jQuery, Moment чи будь-яких залежностей. Свята — `fetch` до Nager.Date з кешуванням.
